# Fotos einsetzen

Legen Sie Fotos einfach mit dem passenden **Dateinamen** in diesen Ordner
(`.jpg`, `.jpeg`, `.png`, `.webp` oder `.avif`). Beim nächsten Build ersetzt das
Foto automatisch die gezeichnete Illustration an allen Stellen der Website –
inklusive automatischer Verkleinerung, WebP-Umwandlung und `srcset`.

Empfehlung: Querformat, mindestens 2000 px breit, JPG in guter Qualität.

| Dateiname           | Motiv                                        | Verwendet auf                   |
| ------------------- | -------------------------------------------- | ------------------------------- |
| `haus-aussen`       | Der Redltalhof von außen (gern am Abend)     | Startseite                      |
| `gaststube`         | Gaststube mit Kachelofen                     | Startseite, Gasthof, Tagesreise |
| `extrazimmer`       | Extrazimmer mit Glasschiebetür               | Gasthof                         |
| `saal`              | Saal (gedeckt, z. B. für eine Feier)         | Gasthof                         |
| `kueche`            | Ein Gericht / die Küche                      | Gasthof                         |
| `tag-fruehstueck`   | Frühstück                                    | Startseite (Tagesreise)         |
| `zimmer-doppel`     | Doppelzimmer                                 | Startseite, Zimmer              |
| `zimmer-einzel`     | Einzelzimmer                                 | Zimmer                          |
| `suite-familie`     | Familiensuite                                | Zimmer                          |
| `suite-gross`       | Große Suite bzw. Balkon                      | Zimmer                          |
| `seminar-gross`     | Seminarraum Erdgeschoss                      | Startseite, Seminare            |
| `seminar-klein`     | Seminarraum Obergeschoss (Lichtdesign)       | Seminare                        |
| `hallenbad`         | Hallenbad                                    | Startseite, Wellness            |
| `sauna`             | Sauna                                        | Wellness, Tagesreise            |
| `dampfbad`          | Dampfbad                                     | Wellness                        |
| `infrarot`          | Infrarotkabine                               | Wellness                        |
| `kneipp`            | Kneippbereich                                | Wellness                        |
| `waldweg`           | Waldweg in der Nähe                          | Startseite (Tagesreise)         |
| `region-redltal`    | Redltal / Wanderweg                          | Region                          |
| `region-wald`       | Hausruck- oder Kobernaußerwald               | Region                          |
| `region-wuerfelspiel` | Frankenburger Würfelspiel                  | Region                          |
| `region-turm`       | Aussichtsturm                                | Region                          |
| `region-lokpark`    | Lokpark Ampflwang                            | Region                          |
| `region-attersee`   | Attersee                                     | Region                          |

> Bitte nur Fotos verwenden, an denen Sie die Nutzungsrechte besitzen, und die
> Quelle im Impressum (Bildnachweis) ergänzen.
